# Accessibility (A11y)

Targeting pragmatic WCAG 2.1 AA alignment.

## Goals
- Keyboard navigability for all interactive controls.
- Visible focus indicators and logical tab order.
- Sufficient color contrast for text and key UI elements.

## Keyboard
- All buttons and segmented controls are standard `<button>` elements.
- Modal: trap focus when open; close on explicit button and backdrop click (escape handling can be added).
 - Importer icon button: circular clickable area with `aria-label="Open file picker"`.

## Tooltips & Charts
- Recharts tooltips are visual; ensure information redundancy in adjacent labels/legends where appropriate.
- Average line is visually distinguished (dashed red).

## Color & Contrast
- Light/Dark themes via CSS variables; maintain ≥ 4.5:1 for body text.
- Non‑text indicators (badges, dots) are supplemented by text labels.
 - Upload icon uses a dark stroke (`#1f2937`) over a light grey circle for contrast.

## Screen Readers
- Images carry meaningful `alt` text.
- Icon buttons include `aria-label`.

## Known Gaps
- Chart elements are not individually focusable; screen reader narration of data points is limited.
- Modal focus‑trap and ESC close deserve a dedicated hook for robustness.
